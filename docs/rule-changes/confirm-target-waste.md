# 확인대상 폐기물: '기준 미만'도 분석결과서로 확인

> 상태: **AI 사전 검토 기반, 전문가 확인 필요** (2026-11-12)

## 문제

법은 오니·광재·분진처럼 유해물질 함량에 따라 지정폐기물이 될 수 있는 폐기물(**확인대상 폐기물**)에 대해,
배출자가 폐기물분석전문기관에 맡겨 지정폐기물인지 **미리 확인**하도록 정한다. 지정폐기물이 **아니라는** 것도 분석결과서로 확인해야 한다.

이전 엔진은 시험 수치 조건을 참으로 만들 때만 성적서를 요구했다. 거짓으로 만들 때는 말로도 받았다.
그래서 제강슬래그에 "용출 농도는 모두 기준 미만이에요"라고 말만 하면 성적서 없이 일반폐기물(51-04-02)로 확정됐다.

## 근거

| 근거 | 위치 | 내용 |
| --- | --- | --- |
| 폐기물관리법(ACT-WASTE) | 제17조제1항제1호 | 유해물질 함유량에 따라 지정폐기물로 분류될 수 있는 폐기물은 폐기물분석전문기관에 의뢰해 지정폐기물 해당 여부를 미리 확인 |
| 배출자신고 업무처리지침(GUIDE-REPORT) | Ⅵ.1.가 (규칙 제17조의2제1항) | 확인대상: 오니류·폐흡착제·폐흡수제 / 광재·분진·폐주물사·폐사·폐내화물·도자기조각·소각재·안정화 또는 고형화·고체화 처리물·폐촉매·수은함유폐기물 처리잔재물 / 기름성분 / 폐석면 / 폴리클로리네이티드비페닐 |
| 같은 지침 | Ⅵ.1.나 (규칙 제17조의2제2항) | 확인 시기: 배출자 신고·변경신고 때, 원료·공정 변경으로 종류·성상이 바뀔 때, 처리 대상 폐기물의 종류·성상이 바뀔 때 |

## 바뀐 것

| 대상 | 이전 | 이후 |
| --- | --- | --- |
| 조건 형식 | `min_status`(참이 되는 데 필요한 증빙)만 | `falsify_min_status`(거짓이 되는 데 필요한 증빙) 추가. 기본 `CLAIMED` |
| 규칙 원본 | - | `knowledge/fact_settings.yaml`에 `confirm_target`(폐기물 종류 목록, 근거, 제외 사실) |
| 빌드 | - | 확인대상 종류의 소재 테이블에서 시험 수치(`cost: TEST`) 조건에 `falsify_min_status: EVIDENCED`를 붙임(PCB 수치 제외) |
| 평가기 | 값으로 거짓이면 상태와 상관없이 거짓 | 상태가 `falsify_min_status`보다 낮으면 모름(`NEEDS_EVIDENCE`) |
| 질문 | 시험 수치를 하나씩 물음 | 참·거짓 모두 서류가 필요한 사실(`evidence_only`)은 묻지 않고 바로 시험성적서를 요청. 이미 서류가 필요한 사실이 있으면 같은 서류로 받을 사실도 묻지 않음 |

적용되는 폐기물 종류(`waste_kind`): `sludge_wastewater`, `sludge_process`, `adsorbent`(폐흡수제 포함), `slag`, `dust`,
`foundry_sand`, `refractory`, `incineration_ash`, `stabilized`, `catalyst`, `mercury_residue`, `asbestos_demolition`.
소재로는 오니 11개, 광재 6개(고로슬래그는 지정 규칙이 없어 사실상 기름성분만 해당), 분진 5개, 소각재 3개, 주물사·폐사 4개, 폐내화물, 폐촉매·이온교환수지 3개, 흡착·흡수제 3개.

## 판정 영향

- 판정표 회귀: develop 기준과 **같음**(MATCH 2863, FEWER_CHOICES 1361, DIFF 57 — DIFF는 이전 변경에서 기록된 것). 회귀 행은 시험 수치를 성적서 값으로 넣기 때문이다.
- 바뀌는 경우(의도한 수정)
  - 확인대상 소재에서 시험 수치를 **말로만** '기준 미만'이라고 하면: 일반 확정 → **성적서 요청**(없으면 판정 불가)
  - 질문 수: 시나리오 REAL-SLUDGE-NO-REPORT 4 → 3회(함수율을 묻지 않고 바로 성적서 요청). 골든 GR-003도 함수율 질문 없이 성적서를 요청한다.
  - 깨끗한 PP·고철·폐지처럼 확인대상이 아닌 소재: **변화 없음**(서류 요구 없음)
- 테스트: `tests/test_confirm_target.py`, `tests/test_rule_changes_d2.py`(오니는 함수율을 묻지 않고 성적서 요청), `tests/test_real_kb.py`.

## 넣지 않은 것 (전문가 확인 항목)

1. **기름성분·PCB**: 목록에 있지만 폐기물 종류가 아니라 성분 기준이다. PCB 조건은 모든 소재에 걸려 있어 넣으면 PCB와 무관한 폐기물(예: PP)도 성적서를 요구하게 된다.
   지금은 확인대상 소재에서도 PCB 수치는 말로 받는다(`exclude_facts`). 폐유(`waste_oil`)의 기름성분도 넣지 않았다.
2. **도자기조각**: 따로 고를 소재가 없다.
3. **확인 시기**: 법은 신고·변경신고 때와 공정·성상이 바뀔 때 확인하도록 한다. 엔진은 시기를 묻지 않고, 확인대상이면 언제나 성적서를 요구한다. 예전 성적서를 그대로 써도 되는지(공정 변경 여부)는 확인하지 않는다.
4. 성적서가 없을 때 맡길 시험 항목·비용·기간 안내는 아직 없다(지금은 '판정 불가'와 시험 항목 목록만).
