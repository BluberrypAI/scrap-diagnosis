# D5: 유기용매가 섞인 산 폐액을 "지정 아님"으로 끝내지 않기

> 상태: **AI 작성, 전문가 확인 필요**. 작성 2026-11-10.

## 발견 경위

공식 질의회신을 정답으로 삼아 엔진을 실행하는 점검에서 발견했다. 시나리오는 작업공간 `planning/legal-scenarios/`에 있다.

- **회신 내용:** 원주지방환경청 게시 지정폐기물 질의·회신 사례 56의 질의 4는 "아세트산은 폐산인가, 폐유기용제인가"를 물었다. 답변 4는 액체로서 pH 2.0 이하면 폐산이고, 폐산에 해당하지 않으면서 유기용매와 섞인 폐기물이면 폐유기용제로 분류할 수 있다고 답했다.
- **기존 엔진:** 산 소재를 고르고 pH 3.0을 입력하면 `NO_GENERAL_CODE`(지정폐기물 아님, 일반 번호는 확인 필요)로 끝났다. 산 경로에는 유기용매가 섞였는지 묻는 질문이 없다.
- **판단:** 회신 기준으로는 지정폐기물일 수 있는 폐액을 "지정 아님"으로 안내한 것이다. 위험한 방향의 오류다.

## 판정 영향

- **판정표 회귀:**
  - CODE/MATCH 2332, STOP/MATCH 233, CODE_CHOICE 1716(MATCH 319, FEWER_CHOICES 1361, DIFF 36)으로 수치는 같다.
  - DIFF 36행 중 18행(pH 2.0 초과 산)은 이전에 `NO_GENERAL_CODE`로 끝났다. 이제는 `ASK_FACT organic_solvent_mixed`에서 멈춘다. 기존 판정표에 이 사실이 없기 때문이며, 의도한 차이다(`tests/test_legacy_regression.py`).
- **골든 평가**(`scripts/eval.py --mock-extractor`): 40/40.
- **대표 시나리오 질문 수**: 변화 없음(`REAL-PP-CLEAN` 5, `REAL-H2SO4` 3 등). 오염 묶음에서 "모두 해당 없음"을 고르면 유기용제 혼합도 "아니오"가 된다.
- **추가 시나리오**(`data/real/scenarios/basic.yaml`, `tests/test_real_kb.py`):
  - `REAL-ACID-SOLVENT-MIX`: 산 + pH 3.0 + 유기용제 혼합 → 해석 필요(질문 7회)
  - `REAL-ACID-WEAK-PLAIN`: 산 + pH 3.0 + 혼합 없음 → `NO_GENERAL_CODE`(질문 3회, 이전과 같음)
- **검토 단위**: 250개에서 251개로 늘었다(법 규칙 151개). `knowledge/README.md`의 개수도 실제 값에 맞췄다. 이전 문서의 249개는 공통 정의 1개를 세지 않은 값이었다.

## 전문가 확인 항목

1. 회신의 원칙이 산뿐 아니라 알칼리 폐액에도 적용되는가. 이번에는 산에만 적용했다.
2. "섞였다"의 기준. 회신에는 혼합 비율 기준이 없다. 미량이라도 섞이면 해당하는가.
3. 해석 필요가 아니라 폐유기용제 번호(04-01·04-02)로 바로 확정해도 되는가. 할로겐족 여부에 따라 번호가 갈린다.
4. pH가 2.0 이하이면서 유기용매가 섞인 경우는 지금처럼 폐산으로 보면 되는가.
