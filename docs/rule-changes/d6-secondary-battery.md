# 규칙 변경 D6: 납축·알칼리 이차전지, 이차전지 스크랩이 일반 번호로 가지 않게

- 상태: **전문가 확인 필요**(AI 사전 검토 기반). 병합 전 도메인 전문가가 아래 "확인할 것"을 판단한다.
- 날짜: 2026-11-11
- 계기: 문진 질문 전체에 대한 다른 AI의 사전 검토(2026-11-11, 저장소 밖 보관). 별표 4의 폐이차전지 지정 번호(03-10)가 엔진에 반영됐는지 확인하라는 지적.
- 대조 결과: 별표 4 번호표(`knowledge/annex4_codes.yaml`)에는 03-10 계열이 이미 있다. 하지만 03-10-01(황산)·03-10-02(알칼리)·03-10-04(스크랩)으로 가는 소재가 없었다. 그래서 납축전지를 "그 밖의 폐이차전지"로 고르면 **51-41-99(일반)**로 판정될 수 있었다(지정 누락 위험).

## 법령 근거와 공백
- 시행규칙 별표 4는 03-10(폐이차전지)을 지정폐기물 번호로 둔다: 03-10-01 황산이 포함된 폐이차전지, 03-10-02 알칼리가 포함된 폐이차전지, 03-10-03 손상된 리튬계, 03-10-04 이차전지 스크랩, 03-10-99 손상된 그 밖의 것.
- 엔진이 가진 시행령 별표 1(지정폐기물의 종류, <개정 2025. 10. 1.>)에는 폐이차전지 항목이 없다(제11호가목의 수은 함유 폐전지만 있음). 제12호 "그 밖에 … 고시하는 물질"로 지정됐는지는 확인하지 못했다.
- 그래서 이미 있던 손상 전지 규칙(`S3-BATTERY-DAMAGED`)과 같이 **해석 필요(관할 기관 확인)**로 판정한다. 결과 카드의 근거에 별표 4의 해당 번호(예: 03-10-01)가 나온다.

## 바꾼 것

| 대상 | 이전 | 이후 |
|---|---|---|
| 새 사실 `battery_type`(이차전지 종류) | 없음 | 리튬계 / 납축전지 / 알칼리 이차전지 / 이차전지 스크랩 / 그 밖의 이차전지 / 이차전지 아님 |
| 새 규칙 `S3-BATTERY-LEAD-ACID` | 없음 | 전지 + 종류 납축 → 해석 필요(근거 별표 4 03-10-01) |
| 새 규칙 `S3-BATTERY-ALKALINE` | 없음 | 전지 + 종류 알칼리 → 해석 필요(03-10-02) |
| 새 규칙 `S3-BATTERY-SCRAP` | 없음 | 전지 + 종류 스크랩 → 해석 필요(03-10-04) |
| `S3-BATTERY-DAMAGED` | 전지면 모두 손상 여부를 물음(일차전지·연료전지·양극재 포함) | 이차전지가 아닌 것은 제외(03-10-03·03-10-99는 이차전지 대상) |
| 새 소재 3개 | 없음 | 폐납축전지(황산 전해액), 폐알칼리 이차전지(니켈카드뮴·니켈수소), 이차전지 스크랩. 일반 번호를 두지 않음(`designated_only`) |
| 일차전지·연료전지·양극재 | - | 종류를 "이차전지 아님"으로 미리 정함(종류 질문 안 함) |
| 전기차·구동용·그 밖의 폐이차전지 | 손상만 물음 | 종류를 묻는다. 납축·알칼리·스크랩이면 해석 필요, 리튬계·그 밖이면 기존처럼 손상 여부 → 일반 번호 |

빌드: `tools/build_kb.py`에 소재 플래그 `designated_only`(일반 번호를 만들지 않음)를 추가했다.

## 판정에 미친 영향

| 사례 | 이전 | 이후 |
|---|---|---|
| "그 밖의 폐이차전지" + 실제로는 납축전지 | 51-41-99 일반 | 종류 질문 → 해석 필요(03-10-01 근거) |
| 폐납축전지(새 소재) | 고를 소재 없음 | 해석 필요(03-10-01 근거), 질문 2개(공통 확인) |
| 하이브리드 차량 니켈수소 전지 | 51-41-05 일반 | 해석 필요(03-10-02 근거) |
| 리튬이온, 손상 없음 | 51-41-99 등 일반 | 같음(종류 질문 1개 추가) |
| 폐일차전지 | 손상 질문 후 51-41-01 | 손상 질문 없이 51-41-01 |

기존 엔진 판정표(4,281행) 회귀: 전지 21행이 바뀌었다(CODE/MATCH 2332 → 2317, STOP/MATCH 233 → 227, 다른 행 36 → 57). 산·알칼리 36행의 기존 차이는 그대로다.
- 전기차·구동용·그 밖의 폐이차전지 18행: 판정표에는 전지 종류가 없어 새 엔진이 종류를 묻는다(`ASK_FACT battery_type`). 종류를 "리튬계"로 답하면 기존과 같은 번호가 나온다.
- 일차전지·양극재·연료전지의 "손상" 3행: 기존 해석 필요 → 일반 번호(51-41-01·07·08). 03-10의 손상 번호는 이차전지만 대상이기 때문이다.
- 기대값은 `tests/test_legacy_regression.py`에 이유와 함께 반영했고, 목록은 `data/real/regression/summary.md`에 있다.

## 전문가가 확인할 것
1. 03-10(폐이차전지)이 지정폐기물인 **시행령 별표 1의 근거**가 있는가(제12호 고시 등). 있으면 해석 필요를 지정폐기물 확정으로 바꾼다.
2. 별표 4 번호표의 판(엔진은 "<개정 2025. 12. 30.>" 추출본)이 현행과 같은가. 다른 AI는 03-10 신설을 2026. 3. 26. 개정으로 봤다.
3. 전기차 배터리에 종류를 묻는 것이 맞는가(하이브리드 니켈수소 전지 때문).
4. "이차전지 스크랩"의 범위(제조 공정 불량 셀·전극 부스러기, 해체 부산물)를 이렇게 안내해도 되는가.
5. 일차전지·양극재·연료전지가 손상됐을 때 일반 번호로 두는 것이 맞는가.
