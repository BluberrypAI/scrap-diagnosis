# 규칙 변경 D1: 비폐기물·적용 제외 과판정 막기

- 상태: **전문가 확인 필요**(AI 사전 검토 기반). 병합 전 도메인 전문가가 아래 "확인할 것"을 판단한다.
- 날짜: 2026-11-09
- 근거 자료: 다른 AI의 법령 사전 검토(2026-11-09, 저장소 밖 보관). 국가법령정보센터 원문과 대조했다는 의견이며, 사람 전문가의 판단을 대신하지 않는다.
- 왜 먼저 하나: S0(폐기물 해당 여부)·S1(법 적용 제외)에서 잘못 "폐기물 아님/적용 제외"로 끝나면 이후의 지정폐기물·번호 판정을 모두 건너뛴다. 오판의 영향이 가장 크다.

## 전문가가 확인할 것
1. "제품·원료로 계속 쓴다"는 답을 **해석 필요**로 끝내는 것이 맞는가. 아니면 특정 조건(같은 사업장 내 원료 사용 등)에서는 폐기물 아님으로 확정해도 되는가.
2. 순환자원은 **인정서 서류**만으로 충분한가. 유효기간·대상 물질·사업장 일치를 따로 물어야 하는가. 지정·고시(제23조) 경로는 어떻게 다룰까.
3. 수산부산물 적용 제외의 **행위 범위**(배출·수집·운반·재활용)를 이렇게 묻는 것이 맞는가.
4. 질병 관련 적용 제외에서 "조치 대상"을 사용자가 판단할 수 있게 묻는 문구가 적절한가.
5. 배출시설 질문을 "설치·운영"으로 바꾼 것이 맞는가.

검토는 검토 카드(`tools/review_kit.py export`)의 해당 카드로 한다. 이 규칙들은 내용이 바뀌어 검토 해시가 새로 정해졌다.
