# 오니 유기성·무기성: 고형물 중 유기성물질 40%

> 상태: **AI 사전 검토 기반, 전문가 확인 필요** (2026-11-13)

## 문제

별표 4는 오니 분류번호를 유기성(51-01)·무기성(51-02)으로 나눈다. 엔진은 구분 기준을 확보하지 못했다고 보고 "폐수처리 오니(유기성·무기성 모름)"·"공정 오니(유기성·무기성 모름)"는 번호를 정하지 않았다(결론 `CODE_NEEDS_TEST`). 성적서에 유기물 함량(예: 71.4%)이 있어도 쓰지 않았다.

## 판정 영향

- "모름" 오니는 성적서에 유기물 함량이 있으면 번호까지 정해진다. 없으면 시험성적서를 요청한다(이전: 번호 없이 끝남).
- 유기성·무기성을 직접 고른 소재(51-01-08, 51-02-01 등)는 변화 없음.
- 판정표 회귀: 유기성·무기성 모름 오니 30행만 달라짐(기존 '시험 필요'로 멈춤 → 이제 유기성물질 함량 성적서 요청). STOP/MATCH 227 → 197, STOP/DIFF 6 → 36. 나머지 동일. 허용 기준은 `tests/test_legacy_regression.py`.
- 골든 시나리오 통과.

## 전문가 확인 항목

1. 별표 5(처리 기준)의 정의를 별표 4(분류번호)의 유기성·무기성 구분에 그대로 써도 되는가.
2. 성적서의 "유기물 함량"이 고형물 기준 값인지(수분 포함 전체 기준인 성적서가 있는지). 고형물 기준이 아니면 환산이 필요하다.
3. "모름" 오니의 일반 번호를 "그 밖의" 번호(51-01-08 / 51-02-01, 공정 51-01-06 / 51-02-19)로 두는 것이 맞는가.
