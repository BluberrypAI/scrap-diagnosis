# 소재별 판정표에서 드러난 문제 (2026-11-05)

`tools/material_tables.py`로 카탈로그 97종(목록에 없음 제외)을 펼친 결과: 4,281행. 표는 `docs/material-tables/`,
기대값은 `tests/data/material_tables.json`, 회귀 테스트는 `tests/test_material_tables.py`.

전제: 폐기물로 내보냄 · 관문 해당 없음 · 배출시설 있는 사업장 · 숫자는 기준값 바로 아래/위 ·
공통 오염 확인(잔류물·기름·PCB·유해화학물질)은 '모두 아니오' + 한 번에 하나만 '예'.

## 바로 고친 것

| 문제 | 수정 |
|---|---|
| 액상·반고상 PP 등에 PCB(또는 유해화학물질·기름 5%)가 겹치면 PCB 번호(08)가 지워지고 소재 번호(01-01-02)로 확정 | 지정 사유가 **모두** 소재 번호 범위와 겹칠 때만 소재 번호로 좁힘(`annex4._all_reasons_match_material`). 테스트: 사유가 여럿인 행은 번호 하나로 정해지지 않아야 함 |
| 포장재·어망·부자·피복전선·우레탄폼·발포수지에 '액상'을 물어 지정 번호 10개 중 고르게 함 | 카탈로그에 `physical_state: solid` 미리 채움 |
| 폐내화물이 일반 번호 2개 중 고르기 | 일반 번호 51-07-01 연결 |
| 오니·비철 광재·전지가 번호 여럿 | 카탈로그 세분(오니 11종, 비철 광재 4종, 전지 6종). 유기성·무기성을 모르는 오니는 번호를 정하지 않고 시험 안내(`CODE_NEEDS_TEST`) |

## 법률 검토가 필요한 것 (일괄 수정 목록)

1. **약한 산·알칼리** — 폐염산 등에서 pH가 지정 기준(2.0 이하 / 12.5 이상)을 벗어나면 지정폐기물이 아니어서 일반 그룹 47개 중 고르게 됨. 소재 9종(산 6·알칼리 3). 일반폐기물일 때 어느 번호인지(예: 51-xx '그 밖의') 근거 필요.
2. **폐이온교환수지가 지정이 될 때** 03-07-01(금속성)·03-07-02(비금속성) 중 무엇인지.
3. **오염으로 지정이 될 때 그룹 안 세부 번호** — 공통 규칙이 그룹(접두어)까지만 정해서 사용자가 고름.
   - PCB → 08-01~04(폐유·폐유기용제·그 밖 액상·그 밖 비액상): 소재(기름·용제)와 상태로 자동 결정 가능해 보임
   - 기름 5% 이상 → 06-01-xx 10개: 기름이 묻은 고체(플라스틱·고철 등)는 어느 번호인지
   - 유해화학물질 → 09 4개
4. **지정 사유가 둘 이상 겹칠 때 어느 번호가 우선인지** — 예: 오니+PCB(01-02 / 08), 광재·분진+PCB(03 / 08), 액상 합성수지+PCB·유해화학물질(01-01 / 08·09), 오니+유해화학물질(01-02 / 09).
   시행령 별표 1의 제외 문구(제6호의 PCB 제외, 제9호의 다른 호 제외)는 `s4_map.designated_exclusions`에 일부만 있음. 나머지 조합의 우선순위 근거 필요. 지금은 목록에서 고르게 둠(지우지 않음).
5. **폐일차전지에 '이차전지 손상' 질문** — 손상 규칙은 이차전지 대상인데 일차전지에도 물음.
6. **잔류물 경로** — 지정폐기물 잔량이 남은 물건은 질의회신 근거라 기본값으로 '기관 확인'에서 멈춤(설계대로). 법령 근거를 찾으면 결론으로 바꿀 수 있음.

## 다음

- 위 1~5는 `rules/materials.yaml`·`rules/s4_map.yaml`·공통 규칙 보완 대상. 근거 자료가 필요한 항목(1·2·3·4)은 Codex 수집 지시 대상.
- 표 검토: `docs/material-tables/<소재>.md`의 '검토' 칸. 검토가 끝난 표는 기대값을 정답으로 고정.
- 공통 오염 항목이 둘 이상 겹치는 경우는 소재 표에서 뺐으므로, 공통 규칙용 조합 표를 따로 만든다.
