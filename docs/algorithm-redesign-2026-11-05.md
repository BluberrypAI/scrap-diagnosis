# 법령 근거 문진 알고리즘 개선 설계와 실행 계획

사용자 승인: ‘일단 현재 버전 커밋하고 작업 시작해’. 체크포인트 `0031937`(590 passed, 4 skipped)을 기준으로 구현한다. 이전 설명의 ‘판정 항목 분리 → 관련 질문 선택 → 항목별 충분성 검사 → 모름·충돌·수정 처리 → 비교 검증’을 실행한다.

## 설계

- 기존 법적 판정 규칙과 S0~S5는 유지한다. 발생 종류는 사용자 확인 사실임을 표시하고 자동으로 성분을 분석했다고 표현하지 않는다.
- 질문 선택은 미확정 규칙의 유효한 첫 조건을 후보로 삼는다. S0의 물질 용도와 S3의 물질 종류는 먼저 확인한다. 그 밖에는 답변 후 최악의 경우에 남는 서로 다른 법적 결론 수를 비교하고, 동률은 기존 질문 순서를 유지한다. 빈도·확률 자료 없이 평균 질문 수가 최적이라고 주장하지 않는다.
- 후보 수가 같더라도 법 적용·금지·후속 코드·신고 판단에 사용하면 질문을 남긴다. 성립 불가능한 규칙과 이미 확인된 조건은 묻지 않는다.
- 결과에 적용 여부, 사용자 확인 종류, 지정 여부, 코드, 일반폐기물 배출자 신고, 지정폐기물 처리계획, 재활용을 분리한다. 미요청·전제 미확인·자료 필요·시험 필요·잠정 결과를 구별한다.
- 신고·계획 검토는 법적 분류를 대체하지 않는 별도 계산이다. 기존 API 호출은 기본 분류 범위를 유지하고, `include_reporting=true`로 확장한다. SCRAP 문진은 확장 범위를 요청한다.
- 일반 신고는 현재의 비지정 배출물과 관련된 사업장 전체 신고대상 배출량(법정 제외량을 뺀 값)을 사용한다. S2의 전체 배출량과 자동으로 동일시하지 않는다.
- 지정 계획은 종류별·묶음별 월평균량, 무조건 대상 종류, 중간가공 예외를 확인한다. 현재 종류만 배출한다고 사용자가 확인하면 그 범위에서 계산한다. 다른 지정 종류가 있으면 법 조문 묶음별 최대 개별량·합계량·무조건 대상 존재를 확인한다. 언급되지 않은 종류를 자동으로 0으로 채우지 않는다.
- 현재 배출물에 적용되지 않는 절차와 사업장 전체에서 의무가 없다는 판단을 구별한다. 공동처리의 대표·구성원, 변경신고·변경확인, 특수 고시 적용은 확인 범위를 명시하고 기관 확인으로 보류한다.
- 근거는 `sources/raw/law-290881.pdf`(기후에너지환경부령 제60호, 2026-10-02) 제18조·제18조의2와 `add-guide-waste-report-pdf.pdf`이다. 2023 설명서만으로 현행 조건을 정하지 않는다. 신규 규칙도 사람 검토 전 `UNVERIFIED`로 유지한다.
- SCRAP 원본을 변경하지 않고 기존 질문 카드·패널·결과 화면 안에 새 상태와 신고 질문을 표시한다. 저장·재확인 정책은 새 사실에도 적용한다.

## 작업 및 인수 조건

1. [ ] **판정 결과와 질문 선택 분리** — 질문 선택 함수를 분리하고, 동률·모름·고비용 시험·후속 위험 사례 및 독립 상태 출력을 RED→GREEN으로 검증한다.
2. [ ] **신고·계획 계산과 근거 표** — 일반 100/300kg·작업 5톤, 지정 월평균 종류별·합계 경계, 중간가공 예외, 다른 종류 미확인, 자료 충돌, 기준일 미지원, 공동처리 보류를 검증한다. 법정 수치는 원문과 자동 대조한다.
3. [ ] **API·MCP·SCRAP 연결** — 확장 범위 저장·복원, 새 질문 도움말, 항목별 결과, 미완료 상태를 반영한다. 구형 호출과 UI의 분류 결과를 구분한다.
4. [ ] **최종 검증** — 전체 pytest, 감사 전후 비교, 실제 화면의 모름→수정→재개·복원을 확인하고 독립 코드 검토를 받는다. 정확도 100%나 실사용 효과를 주장하지 않는다.

## 기록

- 체크포인트: `0031937`, 전체 590 passed / 4 skipped. 원본 `SCRAP.html` 수정 없음.
- 질문 선택 보정: 분기 수만 먼저 비교하면 폐산 성상보다 MSDS 확인을 먼저 물었다. S3에서는 USER→DOCUMENT→TEST의 확인 부담을 우선하고, 같은 부담 안에서 최악의 남은 분기 수를 비교한다. S2의 기존 사업장 확인 순서는 동률 기준으로 보존한다.
