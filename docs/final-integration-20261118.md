# 11월 18일 문진 통합 검증

팀원 PR #15(산·유기용제 혼합 확인)와 #31(지정폐기물 경고·번호 확인 필요 안내)을 최신 develop에 함께 적용했다. 팀원 PR을 원격에서 병합한 것은 아니다.

## 병합과 수정

- knowledge 원본을 함께 보존하고 `tools/build_kb.py`로 data/real 자동 생성물을 다시 만들었다. 자동 생성 파일을 손으로 합치지 않았다.
- 상태 선택지의 쉬운 명칭 `흐르는 액체`와 지정 사유 안내가 일치한다. 실패하던 테스트는 이전 명칭 `액체(흐름)`을 기대했으므로 현재 원본 명칭에 맞췄다. 지정 여부·분류번호 판정은 이 수정으로 바뀌지 않는다.
- handoff의 기존 추정 안내와 새 designated 필드를 모두 보존했다. 새 결과는 추가 필드이며 구형 호출 계약을 삭제하지 않았다.

## 검사

- pytest: **735 passed** (SQLite)
- Ruff 검사·포맷: 통과
- OpenAPI 최신 여부, knowledge → data/real 일치: 통과
- 골든 시나리오: **16/16**, extractor 모의 응답
- 기존 판정표 4,281행: 동일 2,833·후보 축소 1,361·차이 87. 기존 산 혼합·전지·오니의 의도된 차이는 회귀 테스트에서 구분한다. 모든 행이 같은 결과라는 뜻은 아니다.

운영 배포와 실제 법률 전문가 승인은 포함하지 않는다. PostgreSQL 검사는 PR CI에서 별도로 수행한다. 전체 웹 흐름과 실행 조합은 scrap-infra의 `docs/final-integration-20261118.md`에 기록한다.
