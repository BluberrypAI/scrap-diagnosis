# MCP 연결 시험 시나리오

다른 Claude 세션에 `wastecalc` MCP를 연결해, **LLM이 현장 말을 사실 값으로 바꾸고 → 계산기를 부르고 → 결과를 설명하는** 흐름이 잘 도는지 본다.

## 1. 연결

### A. Claude 데스크톱 앱(Code 탭) 또는 Claude Code — 가장 간단
`re_mcp` 폴더를 작업 폴더로 새 세션을 연다. 폴더의 `.mcp.json`이 `wastecalc` 서버를 자동으로 띄운다.
처음 열 때 "프로젝트 MCP 서버를 사용할까요?" 확인이 나오면 허용한다.
연결 확인: 세션에서 "wastecalc 도구 목록 보여줘" → 도구 8개(list_facts, start_assessment, answer_question, evaluate_facts, explain, get_rule, allowed_recycling_types, r_code_definition)가 보이면 성공.

### B. 다른 폴더의 세션이나 다른 클라이언트에 붙일 때
`.mcp.json`의 `wastecalc` 항목(명령·인자·환경변수)을 그 클라이언트의 MCP 설정에 그대로 넣는다.
`.mcp.json`은 이 PC의 절대 경로(Python 3.11, `re_mcp\src`)를 쓴다. 다른 PC에서는 경로를 바꾸거나, `pip install -e .` 후 명령을 `wastecalc-mcp`로 바꾼다.

## 2. 세션 시작 때 붙여 넣을 지시

```
폐기물 분류는 wastecalc 도구 결과로만 답해. 사용자 말을 사실 값으로 바꾸면 한 번 확인받고, 모르면 UNKNOWN으로 넣어. 숫자·조문·분류번호는 그대로 전하고, 도구가 멈추면 안내된 확인 방법을 알려준 뒤 다음 질문을 해. 답은 answer_question의 answers로 여러 개를 한 번에 넣고, 결론이 나거나 사용자가 '왜?'라고 하면 explain으로 근거를 보여줘.
```

## 3. 시나리오

각 시나리오는 첫 발화를 그대로 입력하고, 이어지는 질문에는 '답할 내용'대로 답한다. **확인할 점**을 체크한다.
결과는 기본(strict) 모드에서 대부분 "잠정(NEED_EXPERT)"으로 나온다 — 규칙이 아직 사람 검토 전이기 때문이며 정상이다.

### S-1. 평범한 고철 (끝까지 가는 기본 흐름)
- 첫 발화: "프레스 공장인데 철판 자르고 남은 자투리를 고물상에 넘기려고 해. 대기 배출시설 신고는 돼 있어. 이거 어떻게 분류해?"
- 답할 내용: 기름 안 묻음 / PCB 관련 없음 / 유해화학물질 아님 / 고철 맞음
- 기대: 폐기물 → 사업장폐기물 → 지정폐기물 아님 → 51-29-01 고철 → 재활용 R-3-3, R-4-1, R-10
- 확인할 점: "팔면 폐기물 아니지 않나?"라고 되물어도 LLM이 폐기물이라고 설명하는가(재활용·판매해도 폐기물). 분류번호를 LLM이 먼저 말하지 않고 도구 결과로 말하는가.

### S-2. 작은 공장의 폐유 (생활폐기물로 잘못 빠지지 않는가)
- 첫 발화: "직원 5명 정비소야. 배출시설은 없고 쓰레기는 하루 100kg 정도. 폐엔진오일이 나오는데 이것도 산업폐기물이야?"
- 답할 내용: 공사 아님 / PCB 관련 없음 / 유해화학물질 아님
- 기대: 하루 300kg 미만이고 배출시설이 없어도, 이 폐기물이 폐유(지정폐기물)라서 사업장폐기물 → 06 그룹 번호 선택 질문
- 확인할 점: 생활폐기물이라고 답하지 않는가. "왜 산업폐기물이냐"에 시행령 제2조제6호 이유를 설명하는가.

### S-3. 폐산인데 pH를 모름 (시험 안내)
- 첫 발화: "도금 라인에서 염산 섞인 폐액이 나와. 배출시설 허가 있어. pH는 재본 적 없어."
- 답할 내용: 액체 / 기름 없음 / PCB 관련 없음 / 유해화학물질 아님
- 기대: NEED_TEST — pH 시험(ES 06304.1 유리전극법) 안내, 기준 "pH 2.0 이하면 지정폐기물"
- 확인할 점: pH를 추측하지 않는가. 시험 방법·결과서에 받을 항목(pH, 측정 온도, 시료 채취일)을 전하는가.
- 이어서: "pH 1.2로 나왔어" → 지정폐기물, 02-01 그룹 번호 선택 → "02-01-01" 선택 → 재활용 유형

### S-4. 배출시설이 있는지 모름 (확인 방법 안내)
- 첫 발화: "사출 공장에서 나오는 PP 러너 처리하려는데 우리가 배출시설 사업장인지 모르겠어."
- 기대: NEED_INFO — 배출시설 허가증·신고증명서 확인, 관할 시군구 문의 안내. 하루 300kg 기준 등 다른 길도 함께 안내
- 확인할 점: "모르면 일단 사업장폐기물로 보자" 같은 추측을 하지 않는가.

### S-5. 자투리를 같은 공정에 재투입 (해석 근거)
- 첫 발화: "사출 러너를 분쇄 없이 바로 같은 사출기에 다시 넣어 쓰는데, 이것도 폐기물 신고해야 해?"
- 기대: 폐기물 아님 — 근거가 법 조문이 아니라 2023 설명서 해설 사례라서 잠정·전문가 확인 권고
- 확인할 점: "법적으로 확실히 폐기물 아님"이라고 단정하지 않는가. 분쇄·세척을 거치면 결론이 달라진다는 점을 설명하는가.

### S-6. 기존 서류 번호가 틀린 경우 (모순 감지)
- 첫 발화: "황산 폐액인데 pH 1이고, 예전 신고서에는 51-29-01로 돼 있더라. 그 번호 맞지?"
- 기대: NEED_EXPERT (CODE_MISMATCH) — 지정폐기물(02-01)인데 고철 번호라 맞지 않음
- 확인할 점: LLM이 사용자 말에 맞춰 "맞다"고 하지 않는가.

### S-7. 손상된 리튬배터리 (법령 공백)
- 첫 발화: "불량 나서 부풀어 오른 리튬이온 배터리 셀이 나와. 지정폐기물이야?"
- 기대: NEED_EXPERT (INTERPRETATION_NEEDED) — 별표 4에는 지정폐기물 번호(03-10)가 있으나 시행령 근거 항목을 찾지 못함
- 확인할 점: 확인하지 못한 점(gaps)을 그대로 전하는가.

### S-8. 폐수로 처리하는 경우 (다른 법 적용)
- 첫 발화: "세척 폐수를 우리 공장 폐수처리장으로 바로 보내. 이것도 폐기물이야?"
- 기대: 폐기물관리법 적용 제외 — 물환경보전법 대상
- 확인할 점: 같은 액체도 위탁업체에 폐기물로 넘기면 달라진다는 설명이 나오는가.

### S-9. 기준일 (법령 판)
- 첫 발화: "2020년 1월 기준으로 고철 분류 알려줘."
- 기대: OUT_OF_SCOPE (NO_RULES_FOR_DATE) — 그 날짜의 법령 규칙이 계산기에 없음
- 확인할 점: LLM이 현재 기준 결과로 대신 답하지 않는가.

## 4. 공통으로 볼 것

| 항목 | 좋음 | 나쁨 |
|---|---|---|
| 판정 출처 | 도구를 부르고 결과로 답함 | 도구 없이 기억으로 분류번호를 말함 |
| 사실 변환 | 바꾼 값을 확인받음, 모르면 UNKNOWN | 말하지 않은 사실을 채워 넣음 |
| 숫자·조문 | 기준값·번호·R코드를 그대로 전함 | 300kg을 500kg으로 말하는 등 바꿈 |
| 멈춤 | 확인 방법·시험을 안내하고 다음 질문 | 멈춘 상태에서 결론을 단정 |
| 설명 | '왜'와 입력값 비교를 쉬운 말로 전함 | 조문 이름만 나열 |
| 근거 재확인 | 필요하면 get_rule로 원문을 다시 확인 | 원문을 지어냄 |

문제가 보이면 시나리오 번호, 사용자 발화, LLM 답변, 도구 호출 기록(입력 answers와 결과 status)을 남겨 주면 원인을 찾기 쉽다.
