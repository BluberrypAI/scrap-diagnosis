# SCRAP 디자인과 엔진 연결 문진 화면의 UI 차이

- 비교 대상
  - **디자인**: `SCRAP (1).html`(Figma Make 내보내기). 저장소의 `src/wastecalc/web/scrap/SCRAP.html`과 같은 파일(SHA-256 `30cc7e63ae4b2446…`)
  - **현재 화면**: `src/wastecalc/web/scrap/survey.js` + `survey.css`. 문진 경로(`#/wastes/<id>/survey`)에서만 디자인의 React 문진 화면 대신 그려진다.
- 범위: 문진 화면(L3-Survey)과 그 안의 결과·근거창. 홈·폐기물 목록·순환자원지도·기업 데이터 관리 등 나머지 화면은 디자인 그대로라 차이가 없다.
- 기준일: 2026-11-05. 디자인 문진은 고정 데모(합성수지 → 고체 → 일반 합성수지류 한 경로)이고, 현재 화면은 엔진 결과를 그대로 보여 준다. 차이의 대부분은 여기서 생긴다.

## 한눈에 보기

| 영역 | 디자인 | 현재 화면 | 성격 |
|---|---|---|---|
| 화면 흐름 | 설명 입력 → 이해 확인 → 질문 3개 → 판정 대기 → 결과 | 설명 입력 → 이해 확인 → 질문(필요한 만큼, 묶음 포함) → 결과 | 판정 대기 화면 없음 |
| 질문 수 | 고정 3개, "1 / 3" 표시 | 법령 조건에 따라 6~10화면, "질문 N"(전체 수 없음) | 엔진 특성 |
| 질문 형태 | 보기 하나 고르기만 | 하나 고르기 + 묶음(항목별 예/아니오/모름, 관문 하나 고르기, 성적서 값 입력) + 숫자 입력 | 추가 |
| 우측 패널 | 남은 후보·제외 수·막대·변화·"N개를 M개로" | 같은 구성 + 확인 목적 + 입력한 답 목록(수정·재확인) | 추가 |
| 결과 | 분류번호·근거 3개·재활용 2묶음 | 분류번호·잠정 안내·항목별 확인 결과·확인할 것·신고·처리계획·입력한 답·근거 6단계·재활용 3묶음 | 정보량 많음 |
| 결과 버튼 | 다시 문진하기 / 저장하고 처리 경로 선택 | 다시 문진하기 / 마지막 답 고치기 / 저장한 문진 나가기 | 처리 경로 연결 없음 |
| 나가기 | 확인 모달(계속 작성하기 / 저장하고 나가기) | 모달 없이 바로 폐기물 목록으로 | 빠짐 |
| 아이콘 | SVG 아이콘(화살표·체크·닫기·시계·반짝임·보관함) | 글자 기호(→ ✕ ▤) | 단순화 |

## 1. 상단 작업 막대(L3-WorkBar)

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 나가기 | 누르면 '지금까지 답변은 저장돼 있어요' 모달 | 바로 `#/wastes`로 이동(모달 없음). 답은 서버에 저장되어 같은 주소로 돌아오면 이어서 함 |
| 가운데 제목 | 폐기물 이름(예: 폐합성수지) | '새 폐기물 문진', 분류번호가 정해지면 '51-03-01 폐합성수지류(…)' |
| 저장 상태 | 저장 중... / 자동 저장됨 | 저장한 문진 확인 중… / 저장 중... / 저장 실패 · 다시 시도 / 자동 저장됨 / 문진 시작 전 (실제 저장 결과 반영) |
| 브라우저 뒤로 가기 | 가로채서 나가기 모달을 띄움 | 가로채지 않음 |

## 2. 진행 막대

- 디자인: 질문 순서(1/3, 2/3, 3/3)에 따라 채워짐. 설명 입력·확인 단계는 0%.
- 현재: 판정 단계(S0~S6, 7단계) 기준으로 채워짐. 같은 단계에서 질문이 여러 개면 막대가 멈춰 있다.

## 3. 설명 입력(Survey-Intake)

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 맥락 줄 | '(주)가천정밀 · 새 폐기물 문진' | '새 폐기물 문진'(회사명 없음) |
| 예시 버튼 | 사출 불량품 / '제품 만들고 남은 플라스틱 조각…' | 사출 불량품 / '프레스 공장인데 절삭유 묻은 철 칩…' |
| 베리에게 알려주기 | 항상 누를 수 있음(데모 동작) | LLM이 설정되지 않으면 꺼지고 '설명에서 답을 읽어오는 기능을 사용할 수 없어요' 안내 |
| 읽는 중 | '바로 확인 (데모)' 건너뛰기 버튼 | 없음(실제 LLM 응답을 기다림) |

## 4. 이해 확인(Survey-Confirm)

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 항목 | 고정 4줄: 배출 공정 / 폐기물 / 물질 추정 / 배출량 | LLM이 설명에서 찾은 사실만(개수 가변). 사실마다 체크박스로 빼기 |
| 근거 | 없음 | 항목 아래에 설명 속 근거 문구(“…”) |
| 안내문 | '다르게 읽은 부분이 있다면 수정해 주세요' | '설명에서 확실히 읽힌 것만 골랐어요. 틀린 항목은 체크를 풀어 주세요' |

배출 공정·배출량(월 2.3톤)처럼 판정에 쓰지 않는 정보는 현재 화면에 나오지 않는다.

## 5. 질문 화면(Survey Question)

### 5.1 질문 영역

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 맥락 줄 | '(주)가천정밀 · 10인 사출 공장 · 3번 라인 월 2.3톤 배출' | '새 폐기물 문진 · {판정 단계 이름}'(예: 지정폐기물 여부) |
| 단계 표시 | '1 / 3' | '질문 N'(화면 수 기준, 전체 수 없음) |
| 보조 문구 | 질문별 고정 문구(예: '별표 4가 물질 계열로 먼저 나눕니다') | 엔진이 주는 '왜 묻는지'(규칙의 쉬운 설명) |
| 확인 방법 | 없음 | '어디서 확인하나요?' 펼침(확인할 서류·방법) |
| 시험 안내 | 없음 | 시험이 필요한 질문이면 '시험이 필요해요: 항목 — 방법' |
| 근거 조문 상자 | 2번 질문에만 고정 문장('시행령 별표 1 제1호 가목은 … 로 규정합니다') | 질문이 가르는 조문이 1~2개면 자동 표시('{조문}은(는) “…”로 정합니다'). 법령이 아닌 해설·질의회신이면 '(법령이 아닌 해설·질의회신 자료)' 표시 |

### 5.2 보기

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 보기 카드 | 번호(01~) + 제목 + 작은 설명 | 같음 + 보기마다 '→ 후보 N개' / '후보 N개 그대로' / '분류 대상에서 빠짐' |
| 첫 질문(물질 계열) | 4개(합성수지·플라스틱 / 합성고무 / 목재 / 그 외) | 2단계: 묶음 8개(플라스틱·고무 / 오니 / 기름·용제·페인트 / 산·알칼리·농약 / 광재·분진·재·모래 등 / 석면·수은·전지·방사성 / 의료폐기물 / 그 밖의 것) → 묶음 안 세부 종류. 묶음 카드에는 '후보 36~52개'처럼 범위 표시 |
| 형태 질문 | 쉬운 이름(일반 합성수지류 / PVC / 폴리우레탄폼 / 발포합성수지 / 플라스틱 포장재 / 어망 / 양식용 부자 / 피복 전선) | 법령 명칭(예: '51-03-01 폐합성수지류(폐염화비닐수지류는 제외한다)') + 2023 설명서 뜻풀이(구판 참고) |
| 모름 | 없음 | 모든 선택 질문에 '모름' 보기 |
| 숫자 질문 | 없음 | 숫자 입력칸 + 단위 + '모름' 버튼 |
| 데모 제한 안내 | '데모에서는 합성수지 · 고체 · 일반 합성수지류 경로만 제공돼요.' | 없음 |

### 5.3 묶음 질문(디자인에 없는 화면)

디자인 카드·패널을 그대로 쓰고 본문만 다르다. 정의는 `rules/question_groups.yaml`.

| 묶음 | 화면 |
|---|---|
| 관문(순환자원·다른 법 적용) | '이 물질에 해당하는 것이 있으면 고르세요' — 보기 카드 13개(해당 없음 / 순환자원 인정서 / 다른 법 10가지 / 모름) |
| 오염 확인 | '이 폐기물에 해당하는지 항목마다 골라 주세요' — '모두 아니오' 버튼 + 항목별 질문과 예/아니오/모름 알약 버튼(새 스타일 `.sv-seg`) |
| 분석 성적서 | '분석 성적서의 측정값' — '성적서가 있어요 / 아직 없어요' 카드 → 있으면 항목별 숫자 입력 표(`.sv-report-row`), 없으면 필요한 시험 목록 |

### 5.4 하단 버튼

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 이전 | 앞 질문으로(답은 화면에만 있음) | 서버에 저장된 마지막 답을 되돌림. 묶음 안 세부 보기에서는 묶음 선택으로 돌아감 |
| 다음/결과 보기 | 마지막 질문이면 '결과 보기' | 항상 '다음'. 엔진이 더 물을 것이 없으면 결과로 바로 이동 |
| 안내 | '답변을 선택하면 다음 단계로 이동할 수 있어요.' | 같음. 묶음은 '모든 항목을 고르면 다음으로 넘어갈 수 있어요.' |

### 5.5 우측 패널(CandidatePanel)

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 라벨 | '남은 후보' | '남은 분류번호 후보 · {확인 목적}' |
| 숫자 | 26 → 17 → 8 → 1(고정 데모 값) | 엔진이 센 별표 4 번호 수(예: 272 → 52 → 42 → 8 → 1) |
| 막대 | 26 기준 비율 | 첫 후보 수 기준 비율 |
| 설명 | 'N개 후보를 M개로 줄이는 질문이에요.' + '질문 하나로 9개 후보가 한 번에 제외됐어요' | 고른 보기 기준 'N개 후보를 M개로 줄이는 답이에요' / '이 답으로 후보 수는 그대로예요. {목적}에 쓰는 답이에요' / '이 답이면 분류번호를 정하는 대상에서 빠져요' / 묶음은 'N가지를 한 화면에서 확인해요' |
| 입력한 답 | 없음 | '입력한 답 N개' 펼침: 답마다 수정·다시 선택, 앞 답을 고쳐 다시 확인할 답은 '재확인' 표시, 사업장 정보는 '사업장 정보 · 다음 문진에도 사용' 표시 |
| 숫자 애니메이션 | 숫자가 바뀔 때 튀어나옴 | 같음(숫자가 그대로면 재생하지 않음) |

## 6. 판정 대기(Survey-Waiting)

- 디자인: 5단계 목록('답변을 모아서 읽고 있어요' → … → '허용 재활용 유형을 조회하고 있습니다')을 1.5초씩 보여 주고 결과로 넘어감. '바로 결과 보기 (데모)' 버튼.
- 현재: **없음.** 엔진 계산이 즉시 끝나므로 마지막 답을 저장하면 결과 화면으로 바로 간다.

## 7. 결과 화면(L3-SurveyResult)

### 7.1 머리

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 배지 | '사업장일반폐기물', '배출시설 운영 사업장' | 지정폐기물 판정 결과(예: '지정폐기물 아님(사업장일반폐기물)')와 사업장폐기물 판정 결과('사업장폐기물') |
| 분류번호·명칭 | 51-03-01 / 폐합성수지류 (…) | 엔진 결과 |
| 조회 안내 | '분류번호는 법령 기준표에서 조회한 결과입니다 · 법령 기준일 2026. 10. 30' | 직접 고른 번호면 '명칭을 보고 직접 선택한 번호입니다. 엔진은 앞 단계와의 일치를 확인했습니다', 범위에 번호가 하나뿐이면 '법령 기준표에서 범위를 좁혀 번호를 정했습니다' + '판정 기준일 2026-11-05' |
| 잠정 안내 | 없음 | 사람 검토 전 규칙이면 노란 테두리 '잠정 결과예요 … 관할 기관이나 전문가 확인을 권합니다' |

### 7.2 디자인에 없는 결과 섹션

| 섹션 | 내용 |
|---|---|
| 항목별 확인 결과 | 법 적용 여부 / 발생물질 종류 / 지정폐기물 여부 / 세부분류번호 / 배출자 신고 / 처리계획 확인 / 재활용 유형 각각의 상태(계산 완료·잠정·자료 필요·시험 필요·기관 확인 필요 등) |
| 확인할 것 | '모름'이나 자료 충돌로 남은 질문과 확인 방법·필요한 시험 |
| 신고·처리계획 확인 | 사업장폐기물 배출자 신고 / 지정폐기물 처리계획 확인 대상 여부와 근거 조문 보기 |
| 입력한 답 | 결과 화면에서도 답을 수정·재확인 |
| 문의처·질의서 초안 | 법 조문만으로 정할 수 없을 때 관할 기관 목록과 질의서 초안(펼침) |

### 7.3 판정 근거

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 카드 수 | 3개(질문 1개당 1개: 합성수지·플라스틱 / 고체상태 / 염화비닐수지 아님) | 판정 단계마다 1개, 최대 6~7개(폐기물 여부 / 법 적용 / 사업장폐기물 / 지정폐기물 / 분류번호 / 재활용 …) |
| 카드 내용 | 번호·제목·조문·결론 | 번호·단계 이름·조문·결론 |

### 7.4 근거 조문 창(L4-LawArticle)

| 항목 | 디자인 | 현재 화면 |
|---|---|---|
| 머리 | '폐합성수지 · 51-03-01' / '근거 조문' | '{단계} · {결론}' / '근거 조문' |
| 조문 | 조문 1개 + 인용문 1개 | 근거 조문 최대 2개, 법령이 아니면 '(법령 아님)' |
| 해당 이유 | 2줄(문진 N단계에서 X를 선택 / 판정) | 답한 사실 + 경로마다 해당하지 않은 이유 + 쉬운 설명(10줄 넘게 나올 수 있음) |
| 하단 | '법령 기준일 2026. 10. 30 · 국가법령정보센터 기준' | '{법령 판, 예: 대통령령 제36217호} · 판정 기준일 2026-11-05' |
| 원문 보기 | law.go.kr | 같음(조문 위치로 바로 가지는 않음) |

## 8. 분류번호에 이르지 못한 결과(디자인에 없는 화면)

폐기물이 아님·다른 법 적용·생활폐기물이거나, 시험·자료·기관 확인이 필요해 멈춘 경우.

- 배지: 지금까지 정해진 단계 결과 전부
- 제목: 결론(예: '폐기물 아님') 또는 '확인이 필요해요'
- 본문: 쉬운 설명, 문의처·질의서 초안, 확인할 것, 항목별 확인 결과, 신고·처리계획, 판정 근거
- 디자인의 결과 레이아웃(`sv-result`)과 클래스를 재사용하지만 디자인 시안은 없다.

## 9. 답 수정 창(디자인에 없는 화면)

- 입력한 답의 '수정'을 누르면 근거 조문 창과 같은 오른쪽 패널(`analysis-panel detail-overlay`)이 열린다.
- 선택 질문은 드롭다운, 숫자 질문은 입력칸 + '모름'. '앞 답이 바뀌면 영향을 받는 뒤 답만 다시 확인해요' 안내.
- 디자인은 보기 카드로 답을 고르는데, 수정 창은 드롭다운이라 모양이 다르다.

## 11. 시각 요소

- 아이콘: 디자인의 SVG 아이콘 대신 글자 기호(→, ✕, ▤)를 쓴다. 판정 대기 화면의 시계·보관함 아이콘, 안내 상자의 반짝임 아이콘은 없다.
- 새 스타일(`survey.css`)은 디자인 변수(`--color-primary`)를 쓰지만, 알약 버튼·성적서 입력 표·답 목록·수정 창 입력칸은 디자인 시안이 없어 임의로 만든 모양이다.
- 모바일 폭에서의 배치는 확인하지 않았다(1280×860 데스크톱 폭에서만 확인).

## 12. 디자인 쪽 반영을 검토할 것

1. 묶음 질문 3종(5.3), 숫자 입력, '모름' 보기의 시안
2. 우측 패널의 '입력한 답'(수정·재확인) 영역과 답 수정 창(9)
3. 결과의 추가 섹션(7.2): 항목별 확인 결과, 확인할 것, 신고·처리계획, 문의처
4. 분류번호에 이르지 못한 결과 화면(8)
5. 판정 근거를 질문 단위(디자인)로 보일지 판정 단계 단위(현재)로 보일지
6. 진행 표시: 전체 질문 수를 알 수 없으므로 '1 / 3' 대신 단계 기준 표시 방식
7. 결과 → 처리 경로 선택(`/match`)으로 분류번호를 넘기는 연결
8. 나가기 확인 모달을 다시 넣을지(지금은 답이 서버에 저장되어 모달 없이 나감)
