# 사업장폐기물 추가 자료 수집

기준일 2026-11-04. 목록 80행, 고유 원본 72개(신규 59개, 기존 13개). 본문과 첨부는 파일별로 기록했다. 시행일이 적용되지 않는 판결·참고자료는 판 상태를 비우고 비고에 표시했다.

## 1. 사업장폐기물 범위 해석

- 확보 · 기후에너지환경부예규 제10호 전문 PDF·HWPX, HTML과 연결 이미지 11개, 법제처 16-0534 및 보유 사례집. 지침 PDF 6·8쪽에서 관련 위치를 확인했다. 지침 자체 별표 영역은 비어 있으며 본문은 시행규칙 별표·별지를 인용한다.
- 미확인 · 산정 기간과 포함 범위 전체 및 지정폐기물 합산을 직접 다룬 별도 회신, 신고 면제 시설·복수 사업자의 동일 부지 사례 및 조례 표준안.

## 2. 폐기물 해당 여부

- 확보 · 순환경제사회법·시행령, 순환자원 인정 기준·절차 고시, 대법원 판결 10건, 보유 환경부 사례집의 미강 및 순환자원 사례. 판결 중 인접 쟁점 4건을 비고에 표시했다.
- 미확인 · 동일 공정 재투입을 직접 판단한 대법원 원문.

## 3. 법 적용 제외 경계

- 확보 · 제3조 인용 법률 10종의 기준일 시행판, 시행규칙 제10조 수록 보유본, 원주지방환경청 사례집의 크롬산 폐수 사례 52(PDF 58쪽).

## 4. 사업장폐기물 안에서의 갈래

- 확보 · 건설폐기물법과 시행령 별표 1, 폐기물관리법 시행령 별표 2 PDF.
- 미확인 · 공장 설비 철거·보수 경계를 직접 다룬 질의회신. 2009년 사례집 HWP의 본문 확인이 남았다.

## 5. 재활용 금지·제한

- 확보 · 폐기물관리법·시행령·시행규칙 해당 조문 수록 보유본, 시행령 별표 4의2·4의3, 제한 폐기물 지정 고시 전문. 시행규칙 별표 5의3은 기존 sources/raw/170401495.pdf 경로를 연결했다.

## 6. 예정된 변경

- 확보 · 입법예고 3건의 예고문과 개정안 PDF, 과학원 제449호 행정예고 본문. 폐기물관리법 공포 후 시행 예정 원본 3개를 별도로 연결했다.
- 제2026-614·615호 의견수렴은 2026-08-03 종료. 공포·철회는 미확인. [614호](https://opinion.lawmaking.go.kr/gcom/ogLmPp/87250) · [615호](https://opinion.lawmaking.go.kr/gcom/ogLmPp/87248)
- 제2026-801호 의견수렴은 2026-09-30 종료. 공포·철회는 미확인. [801호](https://opinion.lawmaking.go.kr/gcom/ogLmPp/88200)
- 제2026-449호는 기준일에 시작해 2026-11-30까지 의견수렴 중이다. ZIP은 첨부로 등록됐으나 POST와 GET 요청에 모두 0바이트가 반환됐다. [국립환경과학원 게시물](https://www.nier.go.kr/common/kor/board/comBbsDetail.do?menuNo=13002&bbsNo=241&pstNo=39482&pageIndex=1)
- 공포된 폐기물관리법 시행 예정판은 제21129호 2026-11-12 시행분과 제21850호 2027-01-08 및 2027-07-08 시행분이다. PROPOSED는 수집한 예고문과 개정안의 판 상태를 가리킨다.

## 7. 이전 실패 자료 재시도

- 확보 · 올바로 공지 111210 본문과 XLSX, 환경부 2009년 게시 사례집 HWP. 2018년 게시 재활용 사례집은 보유 PDF와 SHA-256이 같고, 표지에는 2017년 12월 발행으로 표시된다. 2025년 7월판과 원주 2026년 게시 자료는 기존 경로를 연결했다.
- 미확인 · 중앙부처의 2022·2023·2024·2026년 별도 연간판과 분류 설명서 후속판은 공식 도메인 색인에서 확인하지 못했다. 도서관 내부 결과는 확인하지 못했다. 2009년 HWP 본문 대조와 2018년 게시 PDF의 전체 이미지 판독은 남았다.

## 실패 기록과 수동 확인 순서

실패 기록 24행. 초기 실패와 대체 경로에서 확보한 경우도 포함한다. 항목별 검색 근거는 search_log.csv의 item_no로 조회할 수 있다.

- ATTACHMENT_MISSING 7건
- HTTP_ERROR 4건
- HWP_ONLY 1건
- OTHER 4건
- TEXT_UNREADABLE 8건

1. 국립환경과학원 행정예고 게시물 39482에서 첨부 42556-1을 선택한다. 웹 화면에서도 빈 파일이면 게시물의 담당 부서에 공개 원본 경로를 확인한다.
2. 국민참여입법센터의 입법예고·정부입법현황에서 세 안건의 공포·철회 상태를 확인하고 국가법령정보센터 제·개정문 또는 전자관보와 대조한다.
3. 2009년 게시 HWP는 한글 뷰어에서 열고, 2018년 게시 PDF는 페이지 이미지로 본문을 확인한다.
4. 환경정보도서관 현 주소에서 검색 화면이 로드되면 연도별 사례집과 후속 설명서 발행 여부를 확인한다.

## 검증 범위

- PASS · 원본 경로와 SHA-256 대조, 문서 ID 중복 검사, PDF 열기와 압축파일 CRC 검사.
- BLOCKED · 제449호 ZIP 다운로드와 환경정보도서관 내부 검색 결과 확인.
- SKIPPED · HWP 본문 대조, 사례집 전체 이미지 판독, 조문 추출과 기준값 전사.
