# 판정 정책 결정 (규칙 작성자용 요구사항)

판정 규칙(`flow/*.yaml`)은 **적재한 법령(`knowledge/law/`)에서 직접 도출**한다.
이 문서는 법령만으로는 정할 수 없어서 사람이 정한 결정(요구사항)만 담는다. 여기 없는 판단은 조문에서 도출하고,
조문으로도 정해지지 않으면 임의로 정하지 말고 "미결정"으로 표시해 보고한다.

입력 사실은 `flow/facts.yaml`의 이름과 값만 쓴다.

## 출력

| 필드 | 뜻 |
|---|---|
| `outcome` | 아래 클래스 중 하나 |
| `code` | 분류 코드(`NN-NN-NN`). `GENERAL`은 필수, `OUT_OF_SCOPE`는 후보가 있으면 |
| `flags` | `interpretation`(해석에 따른 코드), `route_unsupported`(업체 추천 공정 자료 없음) |
| `blocking_facts` | 결론을 내지 못하고 막혔을 때, 결론을 정하는 데 필요한 미확인 사실 목록 |
| `trace` | 적용된 규칙 ID와 근거 조문 단위 |

| 클래스 | 뜻 |
|---|---|
| `NOT_WASTE` | 폐기물 아님 |
| `CIRCULAR_RESOURCE` | 순환자원(폐기물로 보지 않음) |
| `EXCLUDED` | 폐기물관리법 적용 제외 |
| `HOUSEHOLD` | 생활폐기물 |
| `DESIGNATED_POSSIBLE` | 지정폐기물일 수 있어 멈춤 |
| `OUT_OF_SCOPE` | 우리 범위 밖 |
| `GENERAL` | 사업장일반폐기물 + 코드 |
| `INSUFFICIENT_INFO` | 정보 부족 |

## 결정 사항

- **D1 범위**: 다루는 것은 PP·PE·PET 합성수지 폐기물(`51-03-01`, `51-03-07`)과 금속캔(`51-29-03`)이다.
  그 밖의 폐기물은 `OUT_OF_SCOPE`로 내고, 별표 4에서 후보 코드가 분명하면 `code`에 적는다.
- **D2 지정폐기물은 가능성까지만**: 지정폐기물에 해당할 수 있으면 종류나 코드를 정하지 않고 `DESIGNATED_POSSIBLE`로 멈춘다.
- **D3 내보내지 않는 물질**: 같은 공정에 다시 넣는 등 밖으로 내보내지 않으면 `NOT_WASTE`. (2026-11-19 결정 ③)
- **D4 비고체 합성수지**: 시행령 별표 1 제1호의 "특정시설"은 법령에 정의가 없다. 고체가 아니면(액체·반고체)
  판단하지 않고 `OUT_OF_SCOPE`. (결정 ②)
- **D5 내용물이 남은 용기**: 페인트 용기는 조문대로 판단한다. 페인트 외 내용물이 남았거나 남았는지 모르면
  `DESIGNATED_POSSIBLE`로 멈춘다(비우거나 세척 후 다시 판정 안내). (결정 ④)
- **D6 기름**: 기름성분은 확인대상(시행규칙 제17조의2제1항)이라 말만으로 기준 미만을 확정하지 않는다.
  기름이 있는데 분석 서류(`oil_pct_evidenced`)가 없거나, 기름 여부를 모르면 `DESIGNATED_POSSIBLE`.
- **D7 플라스틱폐포장재(`51-03-07`)**: 별표 4에 정의가 없다. 시행규칙 제10조·제66조·별표 5의3의 용례에 따라
  "자원재활용법 시행령 제18조의 재활용의무 대상 합성수지 포장재"로 본다. 이 코드를 낼 때는 `flags`에
  `interpretation`을 붙인다. (결정 ①)
- **D8 형태로 추정하지 않음**: 필름·병 같은 형태(`input_form`)만으로 포장재라고 추정하지 않는다. 포장재 여부는
  `packaging_used`로만 정한다.
- **D9 순환자원 인정**: 인정은 신청해 인정서를 받는 절차라, 받았는지 모르면 받지 않은 것으로 본다.
- **D10 철 캔**: 법적 코드는 그대로 내고 `flags`에 `route_unsupported`를 붙인다(업체 추천은 알루미늄 캔만 지원).
- **D11 정보 부족**: 결론에 꼭 필요한 사실이 모름이고 위 결정에 보수적 기본값이 없으면 `INSUFFICIENT_INFO`를 내고,
  그 사실을 `blocking_facts`에 넣는다.
- **D12 안전 우선**: 지정폐기물 가능성과 범위 밖 판단이 겹치면 `DESIGNATED_POSSIBLE`을 먼저 낸다.

## 규칙 작성 원칙
- 규칙마다 근거 조문 단위(`문서키/단위ID`)와 원문 인용(`quote`)을 붙인다. 인용은 원문과 글자 단위로 맞아야 한다(공백 무시).
- 근거가 위 결정 사항이면 `decision: D번호`를 붙인다.
- 여러 결론이 겹칠 때의 순서는 법령 구조(예: 지정폐기물은 "사업장폐기물 중"에서 정해짐)에서 도출하고, 근거를 적는다.

## 판정 조정으로 추가한 결정 (2026-11-20)

두 규칙 초안(opus, sonnet)과 골든셋을 비교해 사용자가 정했다.

- **D13 코드가 겹치는 범위 밖 폐기물**: 발포 합성수지 포장재(51-03-06과 51-03-07), PVC 포장재(51-03-03과 51-03-07)는
  별표 4에 우선순위가 없다. 범위 밖으로 안내하고 후보 코드는 정하지 않는다.
- **D14 소용량 의약품 캔**: 자원재활용법 시행령 제18조제1호 마목은 내용량 30mL(30g) 이하 제품 등을 제외한다.
  의약품 캔이면 `medicine_small`을 물어, 소용량이면 제18조 금속캔이 아니다(51-29-04 후보, 범위 밖).
- **D15 범위 밖 안내**: `OUT_OF_SCOPE`에는 `interpretation` 같은 플래그를 붙이지 않는다. 화면에는 "범위 밖 · 지원 예정"만
  보여 주고, 후보 코드는 내부 기록(trace)에만 남긴다.
- 참고(법령 문언, A등급): 캔 순환자원 준수사항을 모르면 지키지 않은 것으로 본다. 지정 고시 별표 2 일반적 준수사항 마목
  "조치를 완료하고 정보 등록을 완료하기 전까지는 폐기물로 보고".

## 문진 화면에서 추가한 결정 (2026-11-20)

- **D16 법 적용 제외 질문의 선택지**: 판정 규칙(30_exclusion)은 그대로 폐기물관리법 제3조 전부를 확인한다. 다만 문진에서
  범위 안 재질(PP·PE·PET·알루미늄·철)의 고체 형태를 고른 경우에는 제3조제1항제1호(방사성 물질과 그로 오염된 물질)만
  묻는다. 제2~9호와 제3항은 물질의 종류 자체(용기에 담기지 않은 기체, 폐수, 가축분뇨, 하수·분뇨, 가축·수산동물 사체 등,
  탄약, 동물장묘시설의 사체, 수산부산물)라서 합성수지·금속 고체 폐기물과 함께 성립하지 않는다. 오염은 어느 재질에나
  생길 수 있어 남긴다. 이 축소는 질문 카드의 선택지에만 적용하고, 다른 값도 판정 보드에서 고칠 수 있다.
