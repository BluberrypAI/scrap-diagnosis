### 예고안

- 제2026-801호 별표 4·4의3의 제안 번호 `51-41-09`는 감사 대상 네 그룹 밖이다. 해당 번호의 기존 `waste_codes.csv`·`allowed_recycling.csv` 행은 각각 0개다. 안 별표 5의 제4호나목14) 신설은 `law_sources.csv`의 `RULE-A5`가 참조하는 범위 안이다. `RULE-A5-MIX`의 제4호다목2)가)(3)은 개정안의 변경 위치에 포함되지 않는다. 안 별표 5의3 제2호나목1)다)(5) 변경 위치에 연결되는 출처 행은 `RULE-A53`이다. 예고 단계에서 현행 인용 문구 영향은 0행이다.
- 제2026-449호는 기름성분 분석의 시료·노말헥산 혼합 과정 변경을 명시한다. 직접 지목된 시험법을 인용한 검토 대상은 `test_methods.csv`의 `TEST-OIL` 1행이다. 관련 메타데이터는 `NIER-OIL`, `NIER-2025-21`이다. 예고 전문 ZIP을 확보하지 못해 개별 인용 셀의 변경 여부와 `TEST-PH` 영향은 `NEEDS_HUMAN`이다.
- 제2026-614호·제2026-615호는 하위법령의 입법예고로 기록했다. 후속 공포본과 실제 시행일은 기준일 검색에서 `NOT_FOUND`다.

## 6. 접근 및 검증 상태

- **PASS —** 정부·공공기관의 공개 법령명 결과, 연혁, 별표·서식, 정책자료, 유역·지방환경청 제목 검색 및 올바로 공개 자료를 확인했다. 경인 업무 자료는 기관 개편에 따른 한강유역환경청 및 수도권대기환경청 자료실을 검색했다. 전북지방환경청은 기존 새만금 경로에서도 검색했다. 실제 검색어와 결과는 [검색 기록](version_search.csv)에 있다. [경인 개편 공지](https://mcee.go.kr/hg/web/board/read.do?boardId=276654&boardMasterId=142&menuId=7001)
- **PASS —** 인용 290셀의 대조표와 대상 그룹 누락·조건 조합을 재검증했다. 검색 기록 55건의 스키마와 보유·추가 원문 54개의 SHA-256을 확인했다. 신규 별표 원문 27개의 출처 및 SHA-256을 [별표 연혁 기록](annex4_history.csv)에 남겼다.
- **BLOCKED —** 국립환경과학원 공고 제2026-449호의 ZIP 다운로드는 HTTP 200으로 빈 본문을 반환했다. 예고 내용은 국민참여입법센터 공개 본문에서 대조했다. 올바로 공지 111210 본문·첨부는 HTTPS 인증서 이름 불일치로 확보하지 못했다. 환경정보도서관 구 주소에서 502가 발생했고, 현 주소의 정적 응답에는 검색 결과가 없었다. 공개 검색 화면의 조회 경로를 재확인하는 중 연결 시간 초과가 발생해 도서관은 웹 색인 범위까지 확인했다.
- **SKIPPED —** 로그인 전용 또는 비공개 자료 검색, 법률 적용 판단. 작업 폴더에 Git 메타데이터가 없어 Git 변경 비교는 수행할 수 없었다.
